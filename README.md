# Knight Wings

A combat flight game for iPhone and iPad (Godot 4.7, Metal), with real aircraft, a huge real-terrain map of
Morocco and the Strait of Gibraltar, ground and air targets, Arcade and Realistic flight, and an in-game
radio that streams from your Navidrome server.

Built on GitHub Actions (no Mac needed). Install the IPA from Releases with SideStore.

- `game/`: the Godot project (open with Godot 4.7.2)
- `tools/`: map and asset pipelines
- `docs/ARCHITECTURE.md`: code contracts
