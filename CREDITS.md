# Credits & Attributions

## Terrain Detail Textures (1024x1024)
All near-ground detail textures in `game/core/world/terrain_textures/` (albedo + normal maps for grass, dry, farm,
forest, rock, sand, snow, urban) are procedurally generated by `tools/make_terrain_textures.py` (numpy + Pillow,
fixed seed). They contain no third-party imagery, so no attribution is required.
